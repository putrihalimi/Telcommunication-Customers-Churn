*Kasus: Analisis Churn Pelanggan Telekomunikasi*
*Latar Belakang:*
Sebuah perusahaan telekomunikasi ingin memahami perilaku pelanggan yang berhenti berlangganan (churn). Churn bisa disebabkan oleh layanan buruk, harga kompetitif, atau faktor lain. Analisis ini bertujuan mengidentifikasi pola dan faktor yang mempengaruhi churn untuk mengurangi kehilangan pelanggan.

*Data:*
- Dataset berisi informasi pelanggan telekomunikasi (demografi, layanan, penggunaan, status churn)
- Variabel: customerID, tenure, MonthlyCharges, InternetService, Contract, Churn, dll.

*Tujuan:*
- Menganalisis profil pelanggan churn vs non-churn
- Mengidentifikasi faktor yang terkait dengan churn

Bagaimana analisisnya berikut urutannya:

1. Import data (pandas)
2. Eksplorasi data (pandas, matplotlib, seaborn)
3. Profil data
4. Cek nilai unik
5. Standarisasi tipe data dan nilai kolom
6. Deteksi nilai outlier (box plot)
7. Lihat distribusi variabel
8. Cek missing value
9. Ganti dan input nilai median etc untuk nilai kolom yang kosong
